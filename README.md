A from-scratch forecaster for GTA VI launch-day Twitch viewers, hour by hour (hours 2–24, five quantiles each). Hinge log-log regression on each case's own comparable launches — stdlib-only Python, deterministic, no network.

## Run it

```sh
MAKEFUN_INPUT_DIR=/path/to/input MAKEFUN_OUTPUT_DIR=/path/to/output python3 main.py
```
